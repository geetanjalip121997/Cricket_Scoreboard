# Cricket Scoreboard Project Using Python

# Project Description

The Cricket Scoreboard Project is a beginner-friendly Python project developed using functions. It calculates a player's strike rate, checks whether the player has scored a half-century, and displays the player's performance summary.

# Features

.Calculates the batter's strike rate.
.Checks whether the batter has scored 50 or more runs.
.Displays the batter's name and total runs.
.Shows the player's performance summary.

#Python Concepts Used
.Functions
.Parameters and Arguments
.Return Statement
.Conditional Statements (if-else)

# Learning Outcomes

Through this project, I learned how to create and call functions, use return statements, apply conditional statements, and reuse functions to avoid code repetition.
